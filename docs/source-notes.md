## 11 月 19 日演示文档和会议逐字稿

本地资料为 `copilot 11.19(1).doc` 和名称以 `逐字稿_copilot11.19_` 开头的 Word 文件。演示文档有步骤和终端截图，自动逐字稿可辅助理解操作顺序。路径、命令和数值应优先与演示文档或后续日志核对。

- 演示先进入项目组配置好的权限环境，激活虚拟环境，再切到 Copilot 应用目录。虚拟环境目录和应用目录分开。
- 启动脚本在应用目录的 `src/start_tune.py`。演示文档记录了将标准输出和错误写入运行日志的命令。项目组说 Python 路径与模型配置已设置，后续操作以当前部署为准。
- 实际演示出现应用重启成功，并进入 benchmark。演示者说明测试流程会把候选参数与 baseline 比较，并可能继续迭代。演示为节省时间中途暂停。
- 候选参数的说明及取值范围由 JSON 给出。项目组还需要确认允许调哪些参数、使用哪台实例以及如何复现对比。每次只启用一个获准目标，应用配置和模型环境配置由内部环境管理。
